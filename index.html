¡Welcome!

Accessible University (AU) is a fictional university, and this is its fictional home page. This page is designed to demonstrate a variety of common web design problems that result in visitors with disabilities being unable to access the content or features of a web page. Although the heading at the top of this section of the page suggests that AU may be a welcoming institution, the inaccessible design of this page sends the opposite message.

¡Bienvenidos!

Universidad Accesible (AU) es una universidad ficticia y esta es su página de inicio ficticia. Esta página demuestra diversos problemas comunes de diseño web que impiden que las personas con discapacidad accedan al contenido o a las funciones de una página web. Aunque el encabezado de esta sección sugiere que AU podría ser una institución acogedora, el diseño inaccesible de esta página transmite el mensaje opuesto.

¿Puedes identificar las barreras?

Esta página tiene al menos 22 problemas de accesibilidad. Encontrarás detalles sobre todos los problemas conocidos en la página de información. Para ver una versión más accesible de esta misma página, consulta la versión accesible. También puedes ver una breve lista de problemas de accesibilidad al seleccionar el botón siguiente.

Problemas de accesibilidad

  1. Faltan regiones de referencia
  2. No hay encabezados
  3. Idioma no especificado
  4. Las imágenes informativas no tienen texto alternativo
  5. Falta texto alternativo en las imágenes decorativas o es excesivo
  6. Contraste de color insuficiente
  7. Se usa el color para comunicar información
  8. La interfaz no es accesible con el teclado
  9. No hay un indicador visible del foco
  10. No hay un enlace para saltar al contenido principal
  11. Texto de enlace redundante o poco informativo
  12. Enlaces en lugar de botones, o viceversa
  13. Menú de navegación inaccesible
  14. Carrusel inaccesible
  15. Cuadro de diálogo modal inaccesible
  16. El formulario no tiene etiquetas adecuadas
  17. CAPTCHA inaccesible
  18. Validación de campos inaccesible
  19. Falta marcado accesible en la tabla
  20. Faltan etiquetas de abreviatura
  21. El contenido de audio del video es inaccesible
  22. El contenido visual del video es inaccesible
