Universidad Accesible

Universidad Accesible (AU) es la página de inicio de una universidad ficticia, diseñada para demostrar diversos problemas comunes de diseño web que impiden que las personas con discapacidad accedan al contenido o a las funciones del sitio. AU fue desarrollada originalmente por AccessIT y es mantenida por AccessComputing; ambos proyectos pertenecen a la Universidad de Washington. Usa el sitio de AU para:

  1. demostrar principios comunes de accesibilidad web en capacitaciones, presentaciones y talleres sobre diseño web accesible.
  2. aprender sobre problemas comunes de accesibilidad web y sus soluciones de forma sencilla.

Disponible en GitHub

Índice de páginas de Universidad Accesible

  1. Antes - Esta página inaccesible demuestra problemas comunes de accesibilidad web mediante la página de inicio ficticia de AU. Observa cuántos problemas de accesibilidad web puedes identificar. NOTA: Como el propósito de esta página es demostrar un diseño web inaccesible, algunas funciones son inherentemente inaccesibles para ciertos grupos de usuarios.
  2. Después - Esta página accesible es una versión modificada de la página Antes, en la que se corrigieron todos los problemas de accesibilidad.
  3. Información - Esta página explica todos los problemas que se muestran en la página de inicio de AU e incluye problemas, soluciones y enlaces a recursos adicionales.
