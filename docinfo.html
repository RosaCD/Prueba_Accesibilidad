Muestras de accesibilidad de documentos de Universidad Accesible

Esta página resume los problemas de accesibilidad que se muestran en los archivos de ejemplo de Word, PDF y PowerPoint que acompañan al sitio de demostración de Universidad Accesible. Para cada problema se sugiere una solución, como se muestra en los archivos accesibles.

HTML

Documento de ejemplo: Versión HTML - Accesible

Este documento puede mostrarse en cualquier navegador web. Usa las herramientas para desarrolladores del navegador para explorar el código fuente cuando necesites mostrar cómo está construido. HTML es mucho más accesible que Word o PDF y establece el nivel de accesibilidad que buscamos alcanzar, en la medida de lo posible, en otros formatos de documentos. Entre las características destacadas del documento HTML de ejemplo se incluyen:

  1. Incluye estilos CSS.

    Todos los estilos están definidos mediante hojas de estilo en cascada (CSS). La familia tipográfica es sans serif y los colores del texto y del fondo cumplen las relaciones de contraste definidas por las pautas WCAG.

  2. La imagen incluye texto alternativo.

    El archivo incluye una imagen con texto alternativo.

  3. Los encabezados están presentes y usan niveles adecuados.

    El archivo incluye encabezados que estructuran el contenido mediante los niveles apropiados.

  4. Las listas están codificadas correctamente.

    El archivo incluye una lista con el marcado adecuado para una lista sin ordenar.

  5. Las tablas tienen un marcado adecuado para los encabezados.

    El archivo incluye dos tablas. La primera tiene una estructura sencilla, con un único encabezado para la fila superior. La segunda es más compleja e incluye celdas combinadas que abarcan varias columnas o filas. Ambas tablas usan el atributo «scope», que proporciona el marcado semántico adecuado para los encabezados de fila o columna.

  6. El idioma está especificado correctamente.

    Este archivo incluye contenido en otro idioma. Los lectores de pantalla admiten varios idiomas y pueden cambiar automáticamente al leer contenido en diferentes idiomas. El párrafo al final del archivo tiene el idioma asignado correctamente, lo que permite que los lectores de pantalla pronuncien el contenido de forma adecuada.

Word

Estos documentos deben mostrarse con la aplicación de escritorio de Microsoft Office 365 o con la versión más reciente de Microsoft Word.

Word - Versión inaccesible

Documento de ejemplo: Versión Word - No accesible

  1. No hay encabezados.

    Evita cambiar el tamaño y poner en negrita el texto para que parezca un encabezado. El uso de estilos de párrafo y encabezados definidos crea la estructura del documento y permite que las personas que usan lectores de pantalla naveguen entre secciones y encabezados.

    Expande el panel «Estilos» y selecciona la casilla «Mostrar vista previa», en la parte inferior del panel. Así podrás ver qué estilos se usan en el documento, si es que se usa alguno. Observa que solo se aplica el estilo «Normal».

  2. Las imágenes significativas no tienen texto alternativo.

    Este documento incluye una imagen: el logotipo de la parte superior de la página, que no tiene texto alternativo. Las imágenes con significado deben incluir texto alternativo para que todas las personas puedan acceder a su contenido.

    Abre el panel de texto alternativo para mostrar el campo vacío. También puedes demostrarlo con el Comprobador de accesibilidad integrado, que señalará este problema como un error.

  3. La lista no se creó con la herramienta de listas.

    La lista de este documento se creó insertando símbolos de viñeta en lugar de usar la herramienta de listas con viñetas. Esto se puede observar al seleccionar la casilla «Mostrar vista previa» en el panel «Estilos».

  4. Las tablas no tienen encabezados definidos e incluyen celdas combinadas.

    Las tecnologías de asistencia leen las tablas de izquierda a derecha y desde la parte superior. Si no se definen las relaciones entre las celdas, la tabla no está correctamente estructurada.

    Abre el cuadro de diálogo «Propiedades de tabla»: selecciona la pestaña «Presentación» de la cinta y luego el icono «Propiedades». En la ventana «Propiedades de tabla», selecciona la pestaña «Fila». En «Opciones», comprueba que estén seleccionadas las casillas «Permitir dividir las filas entre páginas» y «Repetir como fila de encabezado en cada página».

    Este documento también contiene una tabla compleja con celdas combinadas. Las celdas combinadas o divididas pueden dificultar el uso de lectores de pantalla. Con el teclado, coloca el foco en la primera celda de la tabla y usa la tecla Tab para simular cómo una persona que usa un lector de pantalla podría acceder a la información. ¿El orden de lectura es lógico?

  5. Falta asignar el idioma.

    Observa que el texto de la parte inferior de la página está en otro idioma. Office marca algunas palabras con líneas onduladas rojas, como si tuvieran errores ortográficos. Un lector de pantalla configurado en inglés pronunciará este contenido de forma incorrecta. Para definir el idioma de la página, abre el cuadro de diálogo «Idioma», disponible en la pestaña «Revisar» de la cinta.

Word - Versión accesible

Documento de ejemplo: Versión Word - Accesible

  1. Incluye encabezados.

    Este documento usa estilos de párrafo, que sirven como puntos de referencia para que los lectores de pantalla puedan navegar. Expande el panel «Estilos» y selecciona la casilla «Mostrar vista previa», en la parte inferior del panel, para ver los estilos usados en el documento. Puedes modificar los estilos seleccionando el texto y eligiendo «Actualizar encabezado para que coincida con la selección» en el menú desplegable de estilos de párrafo.

    El uso de estilos crea un esquema que se utiliza automáticamente al insertar una tabla de contenido desde la pestaña «Referencias» de Word. En documentos de diez páginas o más, combinar los estilos con una tabla de contenido ofrece ayudas de navegación adicionales que benefician a todas las personas.

  2. Las imágenes incluyen texto alternativo.

    El logotipo de la parte superior del documento incluye texto alternativo. Abre el panel de texto alternativo para mostrar el campo donde se puede revisar la descripción del contenido visual.

    Este panel también incluye un botón para generar texto alternativo automáticamente mediante la inteligencia artificial de Microsoft. Revisa que el resultado generado automáticamente sea preciso.

    Las imágenes de un documento que no tengan un significado importante deben marcarse como decorativas mediante la casilla «Marcar como decorativa».

  3. La lista se creó con la herramienta adecuada.

    Al encontrar una lista en un documento de Word, los lectores de pantalla anuncian cuántos elementos contiene si se creó con la herramienta adecuada. Usa la herramienta de viñetas para las listas con viñetas, la de numeración para las listas numeradas y la de listas multinivel para las listas anidadas. Esta última permite que los lectores de pantalla anuncien correctamente la cantidad de elementos y la posición del foco en la lista y sus sublistas.

  4. Las tablas incluyen encabezados.

    Abre el cuadro de diálogo «Propiedades de tabla»: selecciona la tabla, luego la pestaña «Presentación» y el icono «Propiedades». En la ventana «Propiedades de tabla», selecciona la pestaña «Fila». En «Opciones», la casilla «Permitir dividir las filas entre páginas» debe estar desmarcada. Una tabla bien estructurada no debe tener celdas de datos que abarquen más de una página. Comprueba también que esté seleccionada la casilla «Repetir como fila de encabezado en cada página». Esta opción define la fila superior como encabezado y permite anunciar los datos de la tabla de forma significativa.

  5. El idioma está identificado correctamente.

    Observa que el texto de la parte inferior de la página está en otro idioma. Los lectores de pantalla admiten varios idiomas y pueden cambiar automáticamente al leer contenido en diferentes idiomas. En la mayoría de los documentos, el idioma predeterminado es inglés; para los demás idiomas, establece el atributo de idioma desde la pestaña «Revisar» para que las tecnologías de asistencia pronuncien el contenido correctamente.

PDF

Estos documentos deben mostrarse con Adobe Acrobat Pro DC u otra aplicación que permita ver los paneles «Etiquetas», «Orden de lectura» y «Contenido».

PDF - Versión escaneada

Documento de ejemplo: Versión PDF - Escaneada

  1. El texto no se puede seleccionar.

    Los documentos PDF escaneados con un escáner de superficie plana o capturados con la cámara de un dispositivo móvil suelen guardarse como imágenes. Intenta resaltar el texto con el ratón y observa que no se puede seleccionar. Un lector de pantalla no podrá acceder al contenido de este documento.

    Es necesario aplicar el reconocimiento óptico de caracteres (OCR) para convertir las imágenes de las páginas en texto legible por máquina.

  2. Faltan etiquetas.

    Abre el árbol de etiquetas y observa que este documento no tiene ninguna. Abre también el panel «Contenido» y expande la información de la página: verás que no hay texto, solo imágenes.

PDF - Versión inaccesible

Documento de ejemplo: Versión PDF - No accesible

  1. El texto se puede seleccionar.

    Se puede resaltar o seleccionar el texto con el ratón, lo que indica que los lectores de pantalla pueden acceder al contenido.

  2. Faltan etiquetas.

    Abre el árbol de etiquetas y observa que este documento tampoco tiene etiquetas. Además, abre el panel «Contenido» y expande la página para comprobar que sí hay texto. Los lectores de pantalla y otras tecnologías de asistencia lo anunciarán, pero, sin etiquetas, no hay una estructura semántica ni ayudas de navegación, lo que dificulta la comprensión de la información.

PDF - Versión accesible

Documento de ejemplo: Versión PDF - Accesible

  1. El texto se puede seleccionar.

    Se puede resaltar o seleccionar el texto con el ratón, lo que indica que los lectores de pantalla pueden acceder al contenido textual.

  2. Hay etiquetas.

    Abre el árbol de etiquetas y observa que este documento sí las tiene.

  3. Las etiquetas son semánticamente correctas.

    Coloca el foco en la etiqueta <Sect> superior y usa la flecha hacia abajo del teclado para recorrer el árbol de etiquetas. Observa que los elementos resaltados en el panel de etiquetas también se resaltan en el documento con un rectángulo magenta. Las etiquetas son similares al marcado HTML: proporcionan una estructura semántica adecuada para que los lectores de pantalla anuncien el texto en su contexto. Usa la flecha hacia la derecha para expandir la etiqueta y mostrar su contenido.

  4. Las imágenes incluyen texto alternativo.

    El logotipo de la parte superior del documento incluye texto alternativo. Desde el árbol de etiquetas, muestra el contenido de imagen de la etiqueta <Figure> y abre la ventana «Propiedades del objeto». En la pestaña «Etiqueta», busca el texto alternativo en el campo central. Las imágenes sin significado importante deben marcarse como artefactos mediante el panel «Orden de lectura».

  5. Las tablas incluyen encabezados con identificadores.

    En el árbol de etiquetas, muestra la primera etiqueta principal <Table> y luego su primera etiqueta secundaria <TR>. Observa que el encabezado de la tabla contiene las etiquetas secundarias <TH> correspondientes.

    La segunda tabla es más compleja y necesita identificadores de encabezado para asociar correctamente los encabezados de fila y columna que abarcan varias celdas. En el árbol de etiquetas, muestra la segunda etiqueta principal <Table> y luego su primera etiqueta secundaria <TR>. Revisa los atributos y expande los objetos de atributo para mostrar el <<Dictionary>>.

  6. El atributo de idioma está configurado correctamente.

    En el árbol de etiquetas, muestra la última etiqueta <P> correspondiente al texto en otro idioma. Abre la ventana «Propiedades del objeto» y busca el menú desplegable del atributo «Idioma», en la parte inferior.

PowerPoint

Estos documentos deben mostrarse con la aplicación de escritorio de Microsoft Office 365 o con la versión más reciente de Microsoft PowerPoint. También se recomienda usar el sistema operativo Microsoft Windows.

PowerPoint - Versión inaccesible (presentation_NOTaccessible.pptx)

Documento de ejemplo: PowerPoint - No accesible

  1. Las imágenes significativas no tienen texto alternativo y las imágenes decorativas no están marcadas como tales.

    Las diapositivas 1 y 2 contienen imágenes significativas. Selecciona una imagen y abre el panel de texto alternativo: verás que el campo está vacío. La diapositiva 5 contiene imágenes decorativas en un diagrama creado con SmartArt. Algunos lectores de pantalla anuncian todos los elementos del diagrama, incluidos el texto y los rectángulos de colores del fondo (como diagramas); otros no anuncian nada.

    Es posible asignar texto alternativo a SmartArt. En ese caso, los lectores de pantalla omiten los elementos del diagrama y anuncian el texto alternativo. Sin embargo, quienes usan lectores de pantalla no pueden navegar por el texto alternativo y deben escucharlo de principio a fin.

  2. El texto del enlace no es informativo.

    La diapositiva 2 incluye un enlace activo, pero su texto no es significativo porque muestra la dirección URL.

    Quienes usan lectores de pantalla pueden consultar una lista de los enlaces del documento. Si el texto del enlace activo no es significativo, quizá no sepan a dónde los llevará.

  3. El orden de lectura del contenido de las diapositivas no es correcto.

    Las diapositivas 2 y 3 tienen contenido fuera del orden de lectura esperado. Abre el panel «Orden de lectura» (solo disponible en Windows): selecciona la pestaña «Revisar», luego el menú desplegable «Comprobar accesibilidad» y elige «Panel de orden de lectura». Los objetos de la diapositiva aparecerán ordenados de arriba abajo. Coloca el foco en la parte superior del panel y recórrelo con la flecha hacia abajo. Observa que los elementos resaltados en el panel también se resaltan en la diapositiva, lo que facilita identificar su contenido.

    En macOS, se debe usar el «Panel de selección» para comprobar el orden de lectura. Los elementos aparecen en orden inverso.

  4. Es necesario asignar el idioma.

    La diapositiva 3 contiene texto en otro idioma. Office marca algunas palabras con líneas onduladas rojas, como si tuvieran errores ortográficos. Un lector de pantalla configurado en inglés pronunciará el texto de forma incorrecta.

  5. No se pueden asignar encabezados a las tablas insertadas en las diapositivas.

    La diapositiva 4 incluye una tabla. Selecciónala y abre la pestaña «Presentación de tabla» de la cinta. Observa que el icono «Propiedades» no está disponible.

    Como se trata de una tabla sencilla con una sola fila de encabezado en la parte superior, quizá no represente una barrera para quienes usan tecnologías de asistencia. Puedes confirmarlo abriendo la pestaña «Diseño de tabla» y comprobando que esté seleccionada la casilla «Fila de encabezado».

  6. Los diagramas SmartArt pueden crear barreras.

    La diapositiva 5 incluye un diagrama SmartArt. Los lectores de pantalla pueden tener dificultades para interpretarlo, y el Comprobador de accesibilidad integrado de Office no lo señala en el informe de accesibilidad.

PowerPoint - Versión accesible (presentation_accessible.pptx)

Documento de ejemplo: PowerPoint - Accesible

  1. Las imágenes significativas tienen texto alternativo y las imágenes decorativas están marcadas como tales.

    Las diapositivas 1 y 2 contienen imágenes significativas. Selecciona una imagen y abre el panel de texto alternativo para ver el contenido del campo de texto. En la diapositiva 2 hay varias imágenes agrupadas; cada imagen está marcada como decorativa y el grupo tiene texto alternativo asignado.

  2. El texto del enlace es informativo.

    La diapositiva 2 incluye un enlace activo con texto significativo que indica a quienes usan lectores de pantalla a dónde los puede llevar. También incluye un enlace inactivo que muestra la URL para compartirla durante la presentación y permitir que las personas asistentes la visiten desde sus dispositivos.

  3. El orden de lectura es correcto.

    Todas las diapositivas tienen un orden de lectura lógico. Puedes revisarlo en el «Panel de orden de lectura» de Windows (de arriba abajo) o en el «Panel de selección» de macOS (en orden inverso, de abajo arriba).

  4. El idioma está asignado correctamente al texto en otro idioma.

    La diapositiva 3 contiene texto en otro idioma. El idioma asignado aparece en la barra de estado, en la esquina inferior izquierda de la ventana. Selecciónalo para cambiarlo.

  5. Se usa una plantilla de diapositiva adecuada.

    La diapositiva 5 usa una plantilla modificada que organiza el texto de forma similar a un diagrama SmartArt, pero es totalmente accesible. El contenido adicional de la diapositiva sigue un orden de lectura adecuado y los rectángulos de colores del fondo están marcados como decorativos en el patrón de diapositivas.
